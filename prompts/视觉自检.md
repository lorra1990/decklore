# 提示词 · 视觉自检(闭环第④步)

> 顺序:①机器预检 → ②九宫格看全局 → ③逐页挑毛病。先查溢出——最常见、最显眼。
> 心态(官方 skill 原则):**假定一定有问题,任务是把它找出来**;第一遍没找到 = 没认真看。

## 前置 ①:机器预检(先跑,全绿再看图)

```bash
python3 scripts/precheck.py build/deck.pptx      # 出画布/边距/字号下限/半角标点/文本互撞
python3 scripts/fix_schema.py build/deck.pptx    # 修 pptxgenjs 的 schema 顺序(领导端 WPS 保险)
```

## 前置 ②:转图 + 九宫格总览

```bash
<soffice> --headless --convert-to pdf deck.pptx
rm -f slide-*.jpg
pdftoppm -jpeg -r 150 deck.pdf slide && ls -1 "$PWD"/slide-*.jpg
python3 scripts/contact_sheet.py build/slide-*.jpg   # → sheet.jpg 一张图看全 deck
```

**先看 sheet.jpg 判全局**:版式是否连续重复(两页以上同构=单调)、实底蓝面板是否扎堆、
色彩节奏是否失衡、留白忽紧忽松。全局问题在逐页视角里看不见。

## 逐页挑毛病(发给新鲜眼睛的 subagent,附每页一句 Expected)

「把这几页当 defect 来挑。**假定有问题**,逐页列出观众能看到的问题,轻微的也列:

- 文字溢出 / 被截断(最优先查)
- 元素重叠(文字压形状、线穿字、堆叠错位)
- **标题换行连锁错位**——标题折成两行后,原按一行摆的装饰件/副标题被顶撞
- **脚注 / 来源行与上方内容相撞**
- **文本框过窄导致过度换行**(一行两三个字往下瀑布)
- 没对齐(列不齐、卡片不齐;同类元素间距不一)
- 空白不均(一处挤、一处空;元素间距 < 0.3")
- 边距不足(贴边 < 0.5 英寸;左右留白不对称)
- 低对比(浅字浅底、深图深底;**图标与底色对比不足**)
- 占位符残留(lorem / xxxx / TODO / ［］)
- 逻辑断层(这页和上下页接不上)
- 配色跑了(超出当前风格轨道 `styles/*.md` 的用色)

每页格式:
1. /abs/path/slide-01.jpg(Expected: 封面,大数字带)
2. /abs/path/slide-02.jpg(Expected: 目录,六段)
…

跳过像素级、观众根本看不出的吹毛求疵。列完→改→**只重渲染改过的页**复核一次;
一处修复常引发新问题,改过的页必须复看,但不要无限循环。」

## 已知预览误报(别当缺陷)

- 中文衬线字体在 LibreOffice 转图会回退黑体/苹方 —— **只判版面别判字形**(CLAUDE.md §4)。
- 加粗中文在预览里有"重影"感 —— 合成粗体现象,Windows 雅黑端正常。
