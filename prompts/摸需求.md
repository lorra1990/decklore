# 提示词 · 摸需求(闭环第①步)

> 用产品经理的耳朵,先把"给谁讲、要达成什么"问清,再动手。默认客户是国企 / 金融领导。

## 直接发给 Claude

「在动手做 PPT 之前,先帮我把需求摸清。挑最关键的 2–3 个问我(别一次全问),我答完你再开始立骨架:

1. 听众是谁?级别多高?(决策层 / 业务负责人 / 评审专家)
2. 这场汇报要达成什么?(争取立项 / 汇报成果 / 推动决策 / 对外介绍)
3. 你希望领导听完记住哪一句话?
4. 时长多久?现场是宣讲、评审还是过会?
5. 有没有必须出现的口径?(战略对齐 / 合规安全 / 信创 / 关键 KPI)
6. 有没有现成素材或既定版式要沿用?」

## 摸清的标准

能用一句话说出:

> 「给 ____,在 ____ 场合,用 ____ 分钟,让他们相信 / 同意 ____,记住 ____。」

说不出来就继续问;不要靠猜直接做。
