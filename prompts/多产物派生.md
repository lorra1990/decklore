# 提示词 · 多产物派生(闭环第⑥步)

> 一份主 deck 派生多个产物,口径必须一致。改一处,同步全部。

## 直接发给 Claude

「以这份主 deck 为唯一信息源,派生以下产物,三者口径必须完全一致(同一个数字、同一个序列、同一套措辞):

1. **演讲备注 / 念稿** —— 口语化。每页:开场一句 + 要讲的点 + 过渡到下一页。
2. **讲师手册** —— 详版。每页:讲什么 + 怎么用大白话说 + 可能被问到的问题怎么答。
3. **听众 / 学员速查卡** —— A4 一页。关键词 + 短语,一页能带走。

派生格式见 `templates/`。任何一处数字或顺序改了,提醒我同步到全部产物。」

## 一致性自检

派生完跑一遍:同一个关键数字,在主 deck、备注、手册、速查卡里是不是同一个值?章节顺序是不是一致?
