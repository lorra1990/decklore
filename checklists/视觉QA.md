# 检查清单 · 视觉 QA

> 必做。先转图,再逐页看。

- [ ] 没有文字溢出或被截断(最优先)
- [ ] 没有元素重叠
- [ ] 同类元素对齐(列、卡片、图标)
- [ ] **每页左右留白一致**:内容收在 x=0.5~12.8,多卡行右缘对齐 12.8、不凸出(封面也是)
- [ ] 间距统一(0.3" 或 0.5",别乱混)
- [ ] 距边 ≥ 0.5"
- [ ] 文字与背景对比足够
- [ ] 一种主色 60–70% 主导,**≤3 个强色,没四五色平分秋色**(活泼产品风同样守:别高饱和堆叠、别彩虹卡;活泼≠花哨)
- [ ] 饱和色只打在卡头/分隔页/数字上,背景留中性(暖白/浅底)
- [ ] **框框克制(上档次)**:一页"强容器(实底卡/色块面板)"≤3 个;能用留白 / 细分隔线 / 字号反差表达的别用框。满屏圆角卡 = low
- [ ] **纵向填满(别吊在上面)**:内容带收在 y≈2.15→6.62,最底的块落到 ~6.6;卡片加高后内容垂直居中(别顶对齐留下半空);底栏别压到页脚线(~7.08)
- [ ] **图标克制**:每页 ≤6 枚、只在有意义处、无填充式水印、小节标纯文字(别"太刻意")
- [ ] **状态符号 ✓/✗/⚠ 用小矢量图标、不用文本字形;成列时图标固定 x 对齐成竖列**(✓/✗ 别当文字塞句首)
- [ ] 配色在 `styles/` 风格之内(柔光蓝默认 / soe-finance 三套);柔光蓝禁金、禁纯红绿
- [ ] 数据页有大数字卡,数字醒目
- [ ] 全篇视觉母题统一,经得起逐页投屏看
