# 大纲 → 漂亮 PPT · 操作手册(PLAYBOOK)

> 目的:把"柔光蓝风格 + 圆角版式 + 矢量图标 + 边距纪律"沉淀成一套**可复用、可交付给别人**的流程。
> 拿到**任何一份大纲**,照本手册走,就能稳定产出和 `知识工程_知识中台二期立项_15页.pptx` 同一水准的 deck。
>
> 配套文件:
> - `deck-engine.js` —— 引擎(配色 / 图标 / 圆角版式 primitives)
> - `example-deck.js` —— 最小起手式(四种最常用版式,可直接复制改)
> - `../../styles/soft-blue-unionpay.md` —— 视觉风格规范(配色 / 母题 / 雷区)
> - `../../checklists/` —— 视觉 QA / 内容逻辑 检查清单

## 1. 闭环六步(每次都走)

1. **摸需求** —— 给谁看、要达成什么、听众带走哪句话。默认客户:国企 / 金融领导。
2. **立骨架** —— 把大纲转成"幻灯片序列 + 每页一句主线",先和需求方确认骨架再填内容。
3. **填内容** —— 关键词 + 短语;每个术语第一次出现给一句大白话;成效必须有数字。
4. **视觉自检(必做)** —— 转图逐页看,**先查文本溢出**,再查重叠 / 对不齐 / 留白不均 / 边距不一致。
5. **讲师验收** —— "一个外行能不能照着讲?"指出会卡壳的页、没解释的术语、逻辑跳跃。
6. **出汇报件** —— 按需派生讲师手册 / 念稿 / 速查卡,**所有产物口径一致**(改一处同步全部)。

## 2. 把"大纲段落"映射成"版式模式"

读大纲时,给每一节贴一个版式标签。常用映射:

| 大纲里的内容形态 | 用哪种版式 | 引擎里怎么搭 |
|---|---|---|
| 封面 / 一句话定位 + 关键数字 | **封面 hero 带** | 浅底 + 大标题 + 满宽 `panel` 内嵌半透明数字卡 |
| "N 大能力 / N 个步骤 / N 个模块" | **卡片网格** | `row(n)` 均分 + `tabCard`(彩色卡头 + 白卡身) |
| A vs B / 优劣 / 前后对比 | **两栏对比** | `row(2)` + 两个 `tabCard`(劣=灰、优=蓝) |
| 量化成效 / KPI | **大数字卡行** | `row(n)` + `statCard`(数字用主蓝/柔青) |
| 流程 / 时间线 / 三步走 | **时间轴** | 一条 `LINE` + 圆点(`iconCircle`)+ 阶段 `tabCard` |
| 关键结论 / 收口 / 一句话 | **结论面板** | 满宽 `panel`(中蓝实底 + 白字)+ 1 枚 `chipOnPanel` 徽标 |
| 边界声明 / 风险提醒 | **描边卡** | `card(..., {border: C.warn})` + 陶土三角徽标 |
| 列表 / 分点 | **白卡 + bullet** | `card` + `addText([{bullet:true}])` |
| 概念辨析(本体 vs 实例…) | **并列概念卡** | `row(n)` + `tabCard`,卡身分"= 定义 / 说明" |
| **系统 / 平台 / 架构 / 分层 / 数据流 / 闭环** | **★ 架构图(优先)** | 分层带 = 横条 `panel` 上下堆叠;模块 = 嵌套 `groupBox`/小 `card`;关系 = **连线 + 箭头**(`LINE`,或加箭头的连接件);可加泳道。**一个整体,别拆成一排独立卡** |

> **判断优先级**:一段内容只要能表达成"谁在谁之上 / 谁连到谁 / 数据怎么流",**先考虑架构图**,再退而求其次用卡片网格。架构图条理清晰、上档次(见 `styles/premium-blueprint.md`)。
> 画连线箭头:`pres.shapes.LINE` + `line:{ color, width, endArrowType:'triangle' }`(需要时引擎里加个 `connector(x1,y1,x2,y2)` helper);分层用满宽 `panel` 上下堆叠 + 之间留 `GAP`。
> 起手式 `example-deck.js` 里有封面 / 卡片网格 / 两栏对比 / 大数字 四种现成代码,复制改最快(架构图按本行说明手搭)。

## 3. 硬性纪律(出错最多、最该守)

### 3.1 边距纪律(左右留白必须一致)
- 每页内容**一律收在 `x = 0.5 ~ 12.8`**(`MARGIN ~ RIGHT`),左右各 0.5" 留白。
- 多卡一行**别手算宽度**,用 `row(n, gap)`:它按 `(12.3 - gap·(n-1))/n` 均分,整行自动贴合 0.5 和 12.8。
- 满宽面板一律 `panel(s, 0.5, y, PW-1.0, h)`(= 0.5~12.8)。
- ⚠ 最常见 bug:两张 6.1 宽的卡用 0.5 间隙 → 右缘冲到 13.2,右边只剩 0.1" 留白。**用 `row(2)` 就不会犯**。

### 3.2 图标克制(别太刻意)
- **只在"有意义处"用**:① 每页标题左 1 枚(母题);② 主卡系列(能力 / 接口 / 要素,一类一枚);③ 关键面板 1 枚徽标。
- **不做填充式水印**:引擎里 `iconAt` 带 `transparency` 的调用会被**直接跳过**——别靠半透明大图标填空,空了就靠留白或调比例。
- 一页**显眼图标 ≤ 6 枚**;同一页别混太多不同图标族;小节标题用纯文字(`sectionLabel`),不挂图标。
- 彩色实底面板上的图标 → 用 `chipOnPanel`(白圈 + 彩色图标),别用白图标贴白圈(看不见)。
- **状态符号 ✓/✗/⚠ 用小矢量图标(不用文本字形)**:✓→FaCheckCircle(柔绿)、✗→FaTimesCircle(陶土)、⚠→FaExclamationTriangle。字形跨字体/平台不统一、且跟随文字不对齐。**成列时图标固定同一 x、竖直对齐成一列,文字从图标右侧统一起。**
- **🚫 禁用图标清单(铁律,只增不减)**:❌ **FaBrain(大脑)** —— 俗套 AI 图标,显廉价/模板感,一律不用;模型 / 智能体 / AI 场景改用 **FaMicrochip(芯片)** 等中性专业图标。发现新的"低质/俗套"图标往本清单追加。

### 3.3 配色纪律
- **跨轨道铁律(先定轨道,再配色)**:一种主色 60–70% 主导 + **一个**辅色 + 一个克制点缀,**≤3 个强色,绝不让四五个高饱和色平分版面**;饱和色只打在卡头/分隔页/数字上,背景留中性。**活泼 ≠ 花哨**(尤其活泼产品轨道最易翻车,见 `styles/lively-product.md`)。
- 三条轨道选一:`styles/soft-blue-unionpay.md`(柔光蓝·默认)/ `styles/lively-product.md`(活泼产品)/ `styles/soe-finance.md`(重蓝金)。
- 柔光蓝轨道补充:主蓝主导 + 柔青一个辅色 + 陶土极少;**不用金、不用纯红纯绿**;三级层次都在一个蓝里(中蓝实底 / 淡蓝底 / 白卡)。

### 3.4 文字纪律
- 文本**绝不溢出形状**:放不下就缩字号 / 拆页 / 扩容器。
- 字体规范:**标题=微软雅黑,正文=仿宋(或宋体,小字密集时更清晰),数字/英文/代码=Arial / Consolas**。均为 Windows 自带,目标端原生;macOS 不预装→预览替换为相近字体(雅黑→苹方、仿宋→华文仿宋、宋体→宋体-简),要两端一致就在 PowerPoint 勾"嵌入字体"。引擎已拆 `FONT_TITLE` / `FONT_BODY` / `FONT_NUM`。
- **正文行高 = 1.5**(实战定稿):多行正文 / 分点列表统一 `lineSpacingMultiple: 1.5`(引擎导出 `LH_BODY`)。单行标签 / 大数字 / 表格密集数据不强求;**容器高度按 1.5 预留**,别套旧的紧凑高度否则末行溢出。
- **正文造重点 = 加粗一个焦点**(实战定稿,属"填内容"步):整段正文 / 每个分点,**只加粗一个关键词**(关键数字 / 结论词 / 对比词),给读者视觉落点;**别整句粗、也别一处不粗**。引擎已备 `rt("…**词**…", opt)`(整段)、`rtBul([...], opt)`(分点,字面圆点 + 段末 breakLine,稳)。⚠ pptxgenjs 的 `bullet` 段落属性在"多 run 混排(粗+常规)"时不稳(圆点丢/串行),所以分点统一走 `rtBul`,别手挂 `bullet`。

### 3.4b 对齐多列卡(治"各列项目数不同→标签/结论错位")
- 多列对比(每列"优势/短板/适合产品"之类),**别让每列各自往下堆**——项目数不同就会错行、底部结论框高低不一。
- 做法:**左侧出一次行标签**(优势/短板/适合产品),各列的同名分区**锚定到同一 y、同一 band 高度**;`band` 高度按"最多项目数 + 1.5 行高"预留,项目少的列留白即可(留白 > 错位)。
- 收口行(如"适合产品")用**一条贯穿浅底带**统一高度,别每列一个独立小框(框海=AI 味)。

### 3.5b 纵向间距标准(治"内容吊在上面、底部空一条")
- **内容带 `BTOP=2.15 → BBOT=6.62`,块间距 `GAP=0.3`**;**最底的块底边要落到 `BBOT` 附近**(用 `botY(h)` 锚定),别让内容堆在上半页、底部空一大条。
- 卡片**加高后内容要垂直居中**(`featureCard` 已内置;手搭卡用 `valign:'middle'` 或把内容块算到卡中部),否则加高只会让卡内下半截空。
- 无底栏的纯栅格页(2×N 卡):让卡行填到 `≈BBOT`(`y=BTOP+rr*step`,step 让末行底边≈6.6)。

### 3.5 框框克制 + 上档次(用户反馈"框太多显 low")
- **别把每条信息都塞进实底卡片**。**一页"强容器(实底卡/色块面板)" ≤ 3 个**,其余靠**留白 + 细分隔线 + 字号反差**;框要轻(细线 / 四角角框 > 实底卡海),重实底只留"一页一个关键结论"。
- 想要**炫酷上档次**:判断大纲值不值得 → 上 **`styles/premium-blueprint.md`**(技术蓝图风:hero 插画交图像模型 / canvas 出扁平版,蓝图框架交代码)。**不是每份都上**。
- 一个"留白 + 字体层级 + 一个 hero 视觉"的版面,几乎总比"满屏小卡"高级。

## 4. 生成与自检(命令)

```bash
# 1) 生成(在 templates/deck/ 或 build/ 下)
NODE_PATH=$(npm root -g) node example-deck.js        # 或 build_deck.js

# 2) 转图自检(核心动作)
python3 <pptx-skill>/scripts/office/soffice.py --headless --convert-to pdf out.pptx
rm -f slide-*.jpg
pdftoppm -jpeg -r 120 out.pdf slide                  # 生成 slide-01.jpg ...

# 3) 把 slide-*.jpg 逐页交给"视觉自检"——用 subagent / 新鲜眼睛挑:
#    文本溢出(最优先)> 元素重叠 > 对不齐 > 留白不均 > 左右边距不一致

# 4) 残留占位符
python3 -m markitdown out.pptx | grep -iE "lorem|ipsum|xxxx|TODO|\[insert"
```

> **字体回退提醒**:本机(Mac)+ LibreOffice 转图时,微软雅黑会回退成黑体/楷体,**仿宋/宋体(中文名)会回退成黑体**(看不出衬线)——都是**预览机现象**,不影响 Windows 显示。QA 时只判版面 / 颜色 / 对齐 / 溢出,**忽略字形**。

## 5. 验收清单(交付前过一遍)

视觉:
- [ ] 没有文本溢出 / 截断(最优先)
- [ ] 每页左右留白一致(内容收在 0.5~12.8;多卡行右缘对齐 12.8)
- [ ] 没有元素重叠;同类元素对齐;间距统一
- [ ] 图标克制(每页 ≤6 枚、只在有意义处、无填充水印)
- [ ] 一种主蓝主导,柔青辅,陶土极少;无金 / 无纯红绿
- [ ] 数据页有大数字卡(主蓝 / 柔青)

内容:
- [ ] 有一条能一句话复述的主线;每页只讲一件事
- [ ] 术语 / 缩写第一次出现有大白话;关键英文缩写给中文
- [ ] 成效有数字;合规 / 安全话术该出现就出现
- [ ] 真实人名 / 客户名 / 银行名已脱敏
- [ ] 多产物口径一致(同一数字、同一序列)

## 6. 引擎 API 速查(`createEngine(pres)` 返回)

| 名称 | 作用 |
|---|---|
| `C` / `IK` | 配色(pptx 无#)/ 图标色(带#) |
| `FA` | react-icons/fa 全集(`FA.FaShieldAlt` …) |
| `MARGIN/RIGHT/CONTENT_W/PW/PH` | 0.5 / 12.8 / 12.3 / 13.3 / 7.5 |
| `newSlide(part, title, idx, {foot,total})` | 新内容页(浅底 + 页眉 + 页脚) |
| `addPageTitle(s, Icon, title, sub)` | 大标题 + 左侧圆圈图标(母题) |
| `card / panel / groupBox` | 白卡 / 实底面板 / 虚线分组框(全圆角) |
| `connector(s,x1,y1,x2,y2,{color,both,dash})` | **连线箭头**(画架构图/数据流/闭环),箭头指向终点;水平/垂直最稳 |
| `tabCard(s,x,y,w,H,hH,fill,runs,bodyFill,Icon)` | 彩色卡头 + 白卡身 |
| `statCard(s,x,y,w,h,num,unit,label,accent)` | 大数字卡 |
| `numDot / sectionLabel` | 序号圆点 / 纯文字小节标 |
| `iconCircle / chipOnPanel` | 图标+柔色圆圈 / 面板上白圈徽标 |
| `row(n, gap)` | 一行 n 卡均分,返回 `{w, x(i)}`,自动守边距 |
