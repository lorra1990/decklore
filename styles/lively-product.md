# 活泼产品风格(发布会 / 工具培训轨道)

> 第三条风格轨道。面向**产品 / 工具培训、开发者向、面向非技术学员要"体验感"**的场景。
> 首次落地:AI Agent 工具实战培训(龙虾🦞 / 马🐎 主题)。
> 核心一句话:**明快、年轻、有主题感,但"活泼 ≠ 花哨"** —— 用克制的系统把活泼"管住"。

## 何时走这条轨道

- 产品发布、工具/平台培训、开发者社区、面向 C 端或非技术学员、客户明确要"活泼/有趣/体验感强"。
- **不要用在**:庄重党政 / 年度成果 / 给国企金融领导的正式汇报(那走 `soe-finance.md` 或 `soft-blue-unionpay.md`)。

## 配色(以"龙虾主题"为例,换主题就换主色)

| 角色 | 色值 | 用途 |
|------|------|------|
| 主色 coral | `FF6A45` | 主线/品牌(龙虾)· 卡头、分隔页、强调,占强色 60–70% |
| 深主色 coralDeep | `E8492A` | 主色的深一档,描边/图标 |
| 辅色 indigo | `5A57D6` | **唯一**第二色,绑定一个固定语义(本例=Hermes/马、第二序列) |
| 点缀 amber | `FF9F1C` | 极少量:⭐、关键数字、个别高亮(别铺开) |
| 文字 ink/text | `23203A` / `433D57` | 标题 / 正文 |
| 页底 bg | `FFFBF8` | 暖白(内容页) |
| 封面 / 分隔页 | 深 `201D34` 或满色主色 | 深色封面 + 主色分隔页 + 暖白内容页 = 节奏 |

## 活泼 ≠ 花哨 —— 铁律(这条轨道最容易翻车,务必守)

1. **一主一辅一点缀,≤3 个强色**:主色(coral)60–70% 主导,**一个**辅色(indigo)担第二,点缀色(amber)只用在数字/⭐/个别高亮。**绝不让 3–4 个高饱和色平分版面**(那就是"花"/学生气/AI 味)。
2. **强色打在"安静的画布"上**:背景一律暖白/中性,**饱和色只出现在卡头、分隔页、徽标、数字**——色块要"点",不要"铺满整页"。
3. **一色一义**:每个颜色绑定固定含义(coral=主线龙虾、indigo=Hermes/马、amber=强调),全篇一致,不随机上色。
4. **彩虹卡禁止**:同一行的卡片别每张一个高饱和色乱配;同族/同义才同色。霓虹叠霓虹、渐变铺满、每个元素都上色 = 翻车。
5. **吉祥物/emoji 克制**:🦞/🐎 等 emoji 是点睛(标题、金句、分隔页各一两处),不是每行都贴。
6. **其余纪律照旧**(和别的轨道一致):全圆角、内容收在 `x=0.5~12.8`、文字不溢出、单页显眼图标 ≤6 枚、留白是设计。
7. **字体(统一规范)**:标题=微软雅黑,正文=仿宋(或宋体),数字/英文/代码=Arial / Consolas。均 Windows 自带;macOS 预览会替换为相近字体,要两端一致就 PowerPoint「嵌入字体」。(活泼轨道若觉得衬线正文偏正式,可整轨道把正文换宋体或仍用雅黑,但需我确认。)

## 与另两条轨道的关系

- `soft-blue-unionpay.md`(柔光蓝,默认):单色系、最克制 —— 技术/平台/方法论、要"清爽别 AI 味"。
- `soe-finance.md`(重蓝金):庄重党政/成果汇报。
- 本档(活泼产品):明快有主题 —— 产品/工具培训/体验向。**三条都共享同一套"克制"底线,只是色温和饱和度不同。**

> 一句话:让它**活泼**是为了好上手、记得住;别让它**花**到喧宾夺主、像一键生成。
