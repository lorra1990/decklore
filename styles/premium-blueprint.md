# 上档次原则 + 技术蓝图风(高规格轨道)

> 两部分:**①「上档次」通用原则(所有轨道都适用)** + **② 技术蓝图风(第 4 条风格轨道,高规格时才上)**。
> 起因:用户反馈"之前版本**框框很多、感觉有点 low**",并想要类似"等距机械 + 蓝图网格"那种**炫酷上档次**的观感。
> 决策权交给你:**根据大纲判断这份 deck 值不值得上高规格**,别每份都堆插画。

---

## ① 「上档次」通用原则 —— 先治"框框太多"

> 核心一句:**少即贵。能用留白 + 分隔线 + 字体层级表达的,就别用框。**

1. **框框克制(最关键)**:别把每条信息都塞进实底卡片/面板。**一页"强容器(实底卡/色块面板)" ≤ 3 个**;其余用**留白 + 细分隔线 + 字号反差**组织。满屏圆角卡、事事网格 = low / 模板感 / AI 味。
2. **框要"轻"**:需要框时,优先**细线框 / 四角角框 / 仅顶部一条强调线**,而不是一堆**实底色卡**。重实底只留给"一页一个关键结论"。
3. **留白即高级**:大胆留白,内容不必填满版面;空是设计,不是没做完。
4. **一个 hero 视觉**:一页一个**有分量的主视觉**(插画 / 大图表 / 等距示意),配克制的文字,远胜过 5 张并排小卡。信息多就拆页,别堆卡。
5. **字体层级做功**:用"大标题 + 小注解"的强反差建立层级,替代用框分区。
6. **编辑式 / 不对称**:像杂志/发布会排版,别事事居中、事事等分网格。左图右文、大留白、强对齐线。
7. **克制配色 + 一个母题**:延续各轨道铁律(≤3 强色、活泼≠花哨),母题贯穿全场。

> 自检:**把每页的"框"数出来。超过 3 个强容器,先问"哪几个能换成留白/分隔线/直接排版"。**

## ② 技术蓝图风(第 4 条轨道)

适合:立项 / 发布 / 对外高规格 / 客户明确要"炫酷、有工程质感"。**不适合**:快速内部同步、纯数据周报(用柔光蓝即可)。

### 配色(参考"等距机械蓝图"实拍)
| 角色 | 色值 | 用途 |
|------|------|------|
| 蓝图底 | `F3EFE6` 暖米白 + 极淡网格线 `E2DCCE` | 整页背景 + 工程网格 |
| 钢蓝 ink | `2E4156` / `3E5C7E` | 标题、机械主体、表头深条 |
| 暖琥珀 | `C79A4E` / `D9A441` | 强调、"燃料"、高亮列填充 `E9DBB6` |
| 线描 | `5A6B7E` 细线 | 插画线条、引线标注、四角角框 |
| 正文 | `33414F` | 正文(仍按字体规范:标题雅黑/正文仿宋) |

母题:**四角角框 + 极淡蓝图网格 + 钢蓝/琥珀双色机械 + 等距示意 + 引线标注 + `STRUCTURED DATA FUEL` 式 mono 英文标签**。

### 怎么做(混合工作流 —— 关键)

**hero 插画交给图像模型,框架/文字交给代码。**

- **A. hero 插画(写实等距机械)** → 图像模型(Midjourney / 即梦 / Nano Banana / SDXL)。锁风格靠:**同一风格参考图 + 固定 prompt 词条(isometric, technical blueprint, steel-blue & amber, clean line, off-white grid bg)+ 负面词(no text, no watermark)+ 统一比例**。本环境**无内置图像生成器**,这步需在外部生成,再交给代码合成。
- **B. 蓝图框架 + 排版** → 代码(pptxgenjs 贴图 + 形状,或 HTML/SVG 截图,或 **canvas-design 技能**)。负责:蓝图网格底、四角角框、对比表、引线标注、标题牌、统一皮肤。
- **canvas-design 能到哪**:能做**扁平/线描版**蓝图风(网格、角框、几何齿轮/漏斗/放大镜、表格、排版)——约 90% 氛围;**做不到写实 3D 机械**(那 10% 仍需图像模型)。要纯代码、可进 git、不依赖外部图时,用 canvas/SVG 出扁平蓝图版。

### 退路(没有图像模型时)
纯代码也能出"够看的蓝图风":暖米白网格底 + 角框 + **SVG/canvas 画的扁平几何机械(齿轮=圆+齿、漏斗、放大镜、文档图标)** + 钢蓝/琥珀双色 + 引线标注 + mono 英文标签。比写实弱,但比"满屏圆角卡"高级得多。

## 与其它轨道的关系

- 柔光蓝 / 活泼产品 / 重蓝金 = 三条"代码排版"轨道;**技术蓝图 = 高规格轨道**(可纯代码扁平版,或叠图像模型 hero 插画)。
- **①的"上档次原则"对四条轨道都生效** —— 尤其"框框克制",立刻能把任何一版从 low 拉高一档。
