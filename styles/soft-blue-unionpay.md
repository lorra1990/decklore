# 柔光蓝风格(信创·实拍参考版)

> 用户实拍的银联「知识工程-总体框架」风格抽象出来的视觉策略。当用户说"AI 风太重 / 颜色冲突 / 要圆角 / 参考我拍的图"时,按本指南做,而不是默认的 `soe-finance.md` 重蓝金。
> 核心一句话:**单色系柔光蓝、圆角、浅填充、留白多、几乎不用强对比色**。清爽克制,不是"做来震撼领导"的高饱和色块。

## 为什么换(旧版踩的坑)

旧版(deep navy 13294B + gold C9A24B + red + green)被用户判定"AI 风太重、颜色又重又冲":
- ❌ 近黑藏蓝大色块 + 金 + 红 + 绿,四五种强色互相抢 → 学生气 / 模板感。
- ❌ 每张卡左边一道实色直角竖条 + 整条深色 bar → 硬、重。

## 图标克制(别太刻意 —— 实战教训)

用户反馈过"图标太刻意、感觉混乱"。规则:

- **只在有意义处用**:① 每页标题左 1 枚(母题);② 主卡系列(能力 / 接口 / 要素,一类一枚);③ 关键面板 1 枚徽标。
- **不做填充式水印**:别用半透明大图标去填空卡;空了靠留白或调比例。(引擎 `iconAt` 带 transparency 的调用已设为直接跳过。)
- 一页**显眼图标 ≤ 6 枚**;同页别混太多不同图标族;小节标题用**纯文字**,不挂图标。
- 彩色实底面板上用"白圈 + 彩色图标"徽标(`chipOnPanel`),别白图标贴白圈(看不见)。
- **状态符号 ✓/✗/⚠ 用小矢量图标,不用文本字形**(✓→FaCheckCircle 柔绿、✗→FaTimesCircle 陶土、⚠→FaExclamationTriangle 陶土):字形跨字体/平台不统一、且跟随文字不对齐。**成列时图标固定同一 x 对齐成竖列,文字统一从图标右侧起。**

## 边距纪律(左右留白必须一致 —— 实战教训)

用户对"页面左右留白不一致"很敏感。规则:

- 每页内容**一律收在 `x = 0.5 ~ 12.8`**(左右各 0.5"),封面也不例外。
- 多卡一行**别手算宽度**,用引擎 `row(n, gap)` 均分,整行自动贴合 0.5 / 12.8。
- 满宽面板一律 `0.5` 起、宽 `PW-1.0`(=12.3)。
- ⚠ 高频 bug:两张 6.1 宽卡用 0.5 间隙 → 右缘冲到 13.2,右边只剩 0.1" 留白。

## 形状 / 母题

- **全圆角**:卡片、面板、标签、分组框一律 `ROUNDED_RECTANGLE`,rectRadius ≈ 0.1(短条 0.07)。
- **去掉左侧实色竖条**(圆角 + 直角覆盖条会露角,见 pptx 技能 pitfall);分组靠**填充色 + 圆角 + 细边框**表达。
- **扁平优先**:白卡/淡蓝卡 + 细边框,阴影极弱或不要(参考图是扁平的)。阴影只给悬浮元素(封面数字卡)。
- **三级层次,都在一个蓝里**:中蓝实底(关键结论,白字)/ 淡蓝底(分组面板)/ 白卡(内容)。
- **圆角虚线分组框**:`dashType:'dash'`,淡蓝色,套住一组卡片——照搬实拍图。
- **标题区**:小圆角数字标签(主蓝实底白字「01」)+ 章节名(ink),不写"PART",不画标题下划线。

## 字体(统一规范)

- 标题=**微软雅黑**,正文=**宋体**(默认;实战:仿宋偏细、小字下被判"淡",改用宋体笔画更实更清),数字/英文/代码=**Arial / Consolas**。
- **正文行高 = 1.5**(实战定稿):多行正文 / 分点列表统一 `lineSpacingMultiple: 1.5`,读着透气、不挤。引擎已导出 `LH_BODY = 1.5`,直接用。
  - ⚠ 单行标签、大数字、**表格密集数据**不强求 1.5(给 1.5 会撑高、易溢出);**容器高度要按 1.5 预留**,别套用旧的紧凑高度(否则末行溢出)。
- **正文字号别太小**(实战教训:用户嫌"正文字体有点小"):主体正文 **≥12–13pt**,卡片分点 **≥11pt**,图注 **≥10.5pt**,只有密集表格才用 9–10pt。字号偏小常因"内容吊在上半页、底部空一条"被放大——**先把版面纵向填满**(见纵向间距标准),字就显得稳了。
- **正文造重点 = 加粗一个焦点**(实战定稿):整段正文 / 每个分点**只加粗一个关键词**(关键数字 / 结论词 / 对比词),给读者视觉落点;**别整句粗、也别一处不粗**。引擎已备 `rt("…**词**…")`(整段)、`rtBul([...])`(分点)。⚠ 分点别手挂 pptxgenjs 的 `bullet`(粗+常规多 run 混排时圆点会丢/串行),统一走 `rtBul`(字面圆点 + 段末 breakLine)。
- 均 Windows 自带、领导端原生;macOS 不预装,预览替换为相近字体(雅黑→苹方、仿宋→华文仿宋、宋体→宋体-简),要两端一致就 PowerPoint「嵌入字体」。LibreOffice 转图对中文名衬线字体会回退黑体,**只判版面别判字形**。

## 页码(一页一个,交母板自动字段 —— 实战定稿)

- **每页只放一个页码**,且用 **PowerPoint 自动页码字段**(不手写数字):重排 / 增删幻灯片时自动更新,用户不用手改。
- 引擎做法:`pres.defineSlideMaster({ title, slideNumber:{x,y,align,...} })` + 内容页 `pres.addSlide({ masterName })`;封面用普通 `addSlide`(不挂母板)→ 不显示页码。
- 页眉的"章节序号徽标 + 章节名"(如「03 资质约束」)是**章节标记不是页码**,保留;但**别再另画 `idx/total` 之类第二个页码**(已从 `addHeader`/`addFooter` 移除)。

## 取舍

- 仍要:对齐规整、一页一主题、数据有大数字卡(数字用主蓝/柔青,**不用金**)、合规话术。
- 仍避免:文字溢出、占位符、低对比、为对称硬凑。
- 与 `soe-finance.md` 的关系:那版重蓝金适合"庄重成果汇报";本版柔光蓝适合"技术/平台/方法论"且用户明确要清爽时。**用户拍图要求即以本版为准**。
